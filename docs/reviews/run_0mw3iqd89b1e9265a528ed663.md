## Changes

- **KI-058, click settle.** A click also waits for the main frame's script and document requests, until none has
  been pending for 300 ms, at most 5 s in all (`executor.ts`, `watchRequests`). The generated test's
  `trackActionRequests` does the same, in a new helper template; the previous template stays accepted for saved tests.
- **KI-059, unnamed popup.** Before an action whose next step is a checkpoint, the executor records the notifications
  on the page (alert / status / dialog roles, live regions, open dialogs). With no literal in the requirement, the one
  notification that appeared since is read from the DOM right after the action: visible, or its message without the
  Close button's text. An old notification, or two new ones, give nothing.
- **KI-060, empty counter.** In a numeric_delta, a number read from the DOM on the located element that shows no
  number counts as 0 ("before add (0, no number shown)"). The generated test reads numeric_delta counters with
  `readNumberOrZero`, the same rule.
